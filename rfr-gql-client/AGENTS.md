# Модуль rfr-gql-client

Общие правила находятся в [корневом AGENTS.md](../AGENTS.md), маршруты и операции описаны в [README.md](README.md).

## Назначение и структура

Интерфейс на React/TypeScript и Vite, локальный порт `3001`. Компоненты находятся в `src/components/`, страницы — в `src/pages/`, GraphQL-хуки — в `src/hooks/`, клиенты API и авторизация — в `src/api/`, типы — в `src/types/`, контексты — в `src/context/`. Ресурсы находятся в `src/assets/` и `public/`.

## Особенности изменений

- Используйте отступы в четыре пробела, PascalCase для React-компонентов, camelCase для методов и переменных, шаблон `useXxx` для хуков.
- Используйте MUI и существующую тему `src/theme.tsx`; компоненты обычно размещаются в отдельных каталогах с `index.tsx`.
- Перед созданием компонента или хука проверяйте существующие аналоги в проекте и MUI.
- GraphQL-операции инкапсулированы в хуки. Согласовывайте операции и типы со схемой `rfr-api`.
- Учитывайте нормализацию и обновление кэша Apollo: обновлённая карточка после мутации не доказывает сохранение на сервере, особенно для моков фотографий.
- Авторизация использует Authorization Code + PKCE. В API передаётся access token; id token используется при выходе.
- Переменные `.env`: `VITE_AUTH_URL`, `VITE_API_URL`, `VITE_FRONT_HOST`, `VITE_FRONT_URL`, `VITE_CLIENT_ID`. Адреса должны соответствовать CORS и OAuth redirect URI серверов. Эти настройки не заменяют переменные `RFR_*` тестового модуля.

## Команды из каталога модуля

- `npm ci` — установка зависимостей по lock-файлу.
- `npm run dev` — запуск интерфейса; для работы нужны `rfr-auth` и `rfr-api`.
- `npm run lint` — ESLint, предупреждения недопустимы.
- `npm run build` — проверка TypeScript и сборка Vite.

Для изменений интерфейса выполняйте обе проверки: lint и build. Отдельная команда модульных тестов интерфейса не настроена.
