# Модуль rfr-auth

Общие правила находятся в [корневом AGENTS.md](../AGENTS.md), описание авторизации — в [README.md](README.md).

## Назначение и структура

Сервер OAuth/OIDC на Spring Boot, локальный порт `9001`. Java-код находится в `src/main/java/io/student/rangiffler/`, шаблоны Thymeleaf — в `src/main/resources/templates/`, статические ресурсы — в `src/main/resources/static/`.

Конфигурация сервера и OAuth-клиента находится в `src/main/resources/application.yaml`. БД — MySQL, схема `rangiffler-auth`; миграции — в `src/main/resources/db/migration/rangiffler-auth/`.

## Особенности изменений

- При изменении авторизации учитывайте Authorization Code + PKCE, CSRF, CORS и завершение сессии. Redirect URI должны соответствовать адресам интерфейса.
- Регистрация создаёт учётную запись в auth-БД. API-профиль создаётся отдельно при первом авторизованном запросе пользователя к API.
- Сохраняйте совместимость кодирования паролей с подготовкой пользователей в `rfr-e2e`.
- OAuth-авторизации и ключи хранятся в памяти; после перезапуска может потребоваться повторный вход.

## Команды из корня репозитория

- `./gradlew :rfr-auth:bootRun` — запуск сервера.
- `./gradlew :rfr-auth:build` — сборка и настроенные проверки модуля.

Изменения страниц регистрации и входа проверяйте соответствующими сценариями `rfr-e2e` на запущенном приложении.
